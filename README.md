# ae-albada-rubi.github.io

Pàgina d'inici i política de privadesa de l'Inventari del Cau de l'Agrupament Escolta Albada (Rubí), publicades a https://ae-albada-rubi.github.io.

Google les exigeix per autoritzar l'accés de l'eina al Google Drive de l'entitat, on desa les còpies de seguretat. L'aplicació és al repositori privat `ae-albada-rubi/Gestio-inventari`; la decisió és a `docs/DECISIONS.md` (12 d'octubre de 2026).
